  ArtiSVN — Instrucciones de instalación
══════════════════════════════════════════

Si macOS dice “ArtiSVN está dañado y no puede abrirse”,
ejecuta este comando en Terminal:

  xattr -cr /Applications/ArtiSVN.app

Pasos:

  1. Arrastra ArtiSVN a la carpeta Aplicaciones.
  2. Abre Finder → Aplicaciones → Utilidades → Terminal.
  3. Copia y pega el comando anterior.
  4. Presiona Enter y abre ArtiSVN normalmente.

Solo necesitas hacerlo una vez tras cada instalación.

Migración desde JaviSVN:

  • ArtiSVN usa nuevas rutas de aplicación y datos.
  • La aplicación conserva compatibilidad de migración con la
    configuración y las working copies anteriores.
  • Las integraciones MCP nuevas deben usar artisvn-mcp-bridge.
    El alias javisvn-mcp-bridge es transitorio.
